# Moved to ic-entropy

This crate is retired and intentionally empty. Use
[**ic-entropy**](https://crates.io/crates/ic-entropy) instead.

Replace the dependency with `ic-entropy = "0.6"` and change Rust imports from
`ic_entropy_ic` to `ic_entropy`. Enable `buffered`, `metrics` and `logging` on
`ic-entropy` as needed.

This retirement release provides no APIs, features, forwarding dependency or
compatibility re-exports.
